## ⚡ What is Slam Bot?

</div>

> **Slam Bot** is a Next.js 15 web platform that brings **AI-driven basketball analytics** to life — named after its physical 3D autonomous rover counterpart. The bot analyzes **100+ data points per game** to surface hidden performance insights and help players elevate every slam dunk.

<br/>

## 🚀 Getting Started

### Prerequisites

```
Node.js  v18+
npm / yarn / pnpm / bun
```

### ⚡ Quick Install

```bash
# 🔁 Clone the repository
git clone https://github.com/AakashKavediya/slam_bot.git
cd slam_bot

# 📦 Install dependencies
npm install

# 🚀 Fire up the dev server
npm run dev
```

> Open **[http://localhost:3000](http://localhost:3000)** in your browser 🎉

<br/>

### 🖼️ Add Your Bot Image

```bash
# Drop your robot image into the public folder:
cp slam-bot.png ./public/slam-bot.png

# It will then render in this README automatically via:
# ![Slam Bot](./public/slam-bot.png)
```
